Swiggy Sales Dashboard - Power BI

## Dataset

The dashboard dataset is [`Swiggy_PowerBI_Dataset.csv`](./Swiggy_PowerBI_Dataset.csv), a synthetic sample containing 5,000 orders dated from 2025-01-01 through 2026-06-25. It includes order dates, city and restaurant category, customer age, item counts, order amounts, delivery fees and times, distance, payment mode, customer ratings, order status, and coded order and delivery-partner IDs.
